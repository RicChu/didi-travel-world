## 這三天你不需要做任何決定

熱氣球是卡帕多奇亞唯一會浮動的項目，而**停飛時業者會直接把你延後一天**——不用打電話、不用喬座位、不用改行程。四個 Plan（A / B / C / D）的白天完全相同，差別只有「04:00 起床發生在哪一天」：

| | 04:00 起床在 | 你要開的車 |
|---|---|---|
| Plan A | 11/02 | 完全照表，**11/02 上午不開車**（補眠） |
| Plan B | 11/03 | 11/02 上午多開 35 分（Paşabağ + Zelve）；11/03 整天往後平移 30 分（09:30 出發），路線順序不變 |
| Plan C | 11/04 | 11/04 熱氣球從 **Gamirasu** 接（已確認）；累的話跳過 Avanos，改 Gamirasu → Sarı Han（**40 分**）→ ASR |
| Plan D | 無 | 完全照表 |

**你唯一要記住的事：11/02 和 11/03 晚上都要 22:00 前睡**，因為隔天可能 04:00 起床，而你要開車。

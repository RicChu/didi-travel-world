## 卡帕多奇亞紅線 / 綠線疲勞度

> 下面這張表是**當初決定怎麼分配三天時的比較依據**，保留備查。實際定版的排法見下一節，不是「紅線一天、綠線一天」的原始形式——駱駝吃掉了紅線的三個點，紅線只剩露天博物館，被塞進 11/02 下午；綠線則拆成 Kaymaklı（遠點）與 Uçhisar / 鴿子谷（Göreme 後院）兩塊排在 11/03。

結論：**綠線比紅線累**。綠線累在距離長、點位分散、地下城與 Ihlara / Selime 會消耗體力；紅線累在景點密度高、拍照點多，但大多集中在 Göreme / Avanos 周邊，車程短很多。

| 項目 | Green 線 | Red 線 |
|------|----------|--------|
| 疲勞度 | 高，尤其熱氣球後再跑完整 Ihlara / Selime | 中，景點多但移動短 |
| 自駕時間 | 完整版約 4～5 小時；精簡版約 2～2.5 小時 | 約 1.5 小時，繞一圈回 Göreme |
| 景點時間 | 完整版約 4～5 小時；精簡版約 2～3 小時 | 約 4～5 小時 |
| 一天總長度 | 完整版約 8～10 小時；精簡版約 4～6 小時 | 約 6～8 小時 |
| 最累原因 | 長距離自駕 + 地下城 + Ihlara Valley / Selime | 景點密集 + 退房寄放行李 + 換飯店 |
| 建議用法 | 適合放在沒搭到熱氣球、體力較完整的那天；若前一天已完成 red 線，隔天再走 green 線 | 適合放在熱氣球飛成的那天，或 11/03 需要銜接換飯店時；若接駱駝，red 線必須精簡 |

紅線 / 綠線 / 駱駝決策規則（見 [行程.md](./行程.md)）：**只有熱氣球浮動**。白天行程完全相同，差別只有「04:00 起床發生在哪一天」。⚠️ **停飛不會自動順延**，需當下跟業者確認隔天有無位子，滿了就全額退款。

- **11/02 = 熱氣球（浮動）+ Paşabağ + Zelve + 露天博物館 + 16:00 駱駝（日落場）**。**有飛**：不吃早餐、補眠到 11:00，11:15 鎮上早午餐，三個景點壓縮 40 分（Paşabağ 30 / Zelve 30 / 露天博物館 1h30 不動）。**沒飛**：09:30 早餐、10:10 出發，景點不壓縮。駱駝含 Red / Rose（不含 Ortahisar），自駕跳過這幾點，所以紅線只剩露天博物館一個必去點。露天博物館排下午不是妥協，是因為**旅行團集中在上午**。
- **11/03 = Kaymaklı（第一站）→ 鴿子谷 → Seki 午餐 → Uçhisar Castle → Çavuşin 老村 → 愛情谷看日落 → 回 Henna**。連住三晚不搬家，行李整天在房間。補飛版整條路線**倒過來走**（Uçhisar → Seki → Kaymaklı → 鴿子谷日落），因為 Kaymaklı 冬季 17:00 關門、末班入場約 16:00。
- **11/04 = Mustafapaşa 希臘石屋村 + Avanos 小鎮（Güray Müze + Chez Galip 頭髮博物館，停一次車走完）+ Sarı Han 商隊驛站** + ASR**。⚠️ **三天裡唯一行李必須待在車上的一天。**

**駱駝永遠固定 11/02 16:00**（GetYourGuide 日落場，**11/02 Göreme 日落 17:41**，騎乘 16:20～17:20 整段落在黃金時段）：它的免費取消期限是 11/01 16:00，而那時還不知道 11/02 熱氣球會不會飛，所以「等消息再決定」這條路本來就不存在。釘死之後 11/02 + 11/03 的總車程從浮動版的 145 分降到 **120 分**，而且永遠不需要取消。

### 11/03 的 120 分車程怎麼來的

| 路段 | 車程 |
|---|---|
| Göreme → **Kaymaklı** | 35 分 |
| Kaymaklı → 鴿子谷 | 40 分 |
| 鴿子谷 → Uçhisar | 5 分 |
| Uçhisar → 回 Göreme | 10 分 |
| 鎮內機動 | 30 分 |
| **合計** | **120 分** |

**行李全天不上車**，15:15 就回到飯店。Kaymaklı 放第一站，因為它是全天停最久（1.5h）、離飯店最遠（32 km）的點，早上人也最少。

### 每日疲勞度總覽

疲勞度以交通時間、早起程度、換飯店 / 取還車、景點步行量與是否有深夜抵達綜合判斷。等級定義：`低` = 可慢走與休息；`中` = 正常景點日；`中高` = 需要控體力；`高` = 當天容易累積疲勞；`很高` = 需要預留刪減方案。

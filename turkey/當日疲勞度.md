## 卡帕多奇亞紅線 / 綠線疲勞度

> 下面這張表是**當初決定怎麼分配三天時的比較依據**，保留備查。實際定版的排法見下一節，不是「紅線一天、綠線一天」的原始形式——駱駝吃掉了紅線的三個點，紅線只剩露天博物館，被塞進 11/02 下午；綠線則拆成 Kaymaklı（遠點）與 Uçhisar / 鴿子谷（Göreme 後院）兩塊排在 11/03。

結論：**綠線比紅線累**。綠線累在距離長、點位分散、地下城與 Ihlara / Selime 會消耗體力；紅線累在景點密度高、拍照點多，但大多集中在 Göreme / Avanos 周邊，車程短很多。

| 項目 | Green 線 | Red 線 |
|------|----------|--------|
| 疲勞度 | 高，尤其熱氣球後再跑完整 Ihlara / Selime | 中，景點多但移動短 |
| 自駕時間 | 完整版約 4～5 小時；精簡版約 2～2.5 小時 | 約 2～3 小時，含回 Grand Elite 拿行李與開去 Gamirasu |
| 景點時間 | 完整版約 4～5 小時；精簡版約 2～3 小時 | 約 4～5 小時 |
| 一天總長度 | 完整版約 8～10 小時；精簡版約 4～6 小時 | 約 6～8 小時 |
| 最累原因 | 長距離自駕 + 地下城 + Ihlara Valley / Selime | 景點密集 + 退房寄放行李 + 換飯店 |
| 建議用法 | 適合放在沒搭到熱氣球、體力較完整的那天；若前一天已完成 red 線，隔天再走 green 線 | 適合放在熱氣球飛成的那天，或 11/03 需要銜接換飯店時；若接駱駝，red 線必須精簡 |

紅線 / 綠線 / 駱駝決策規則（見 [行程.md](./行程.md)）：**只有熱氣球浮動，而且停飛由業者自動延後一天，現場不需要做任何決定**。四個 Plan（A / B / C / D）的白天行程完全相同，差別只有「04:00 起床發生在哪一天」。

- **11/02 = 熱氣球（浮動）+ 12:00 午餐 + 13:30～15:20 露天博物館 + 16:00 駱駝（日落場）**。沒飛的上午（Plan B/C/D）補 **Paşabağ + Zelve**（09:30～12:05，車程 35 分）。駱駝含 Red / Rose（Klook 那團另含 Ortahisar，GetYourGuide `t486222` 沒有），自駕跳過這幾點，所以紅線只剩露天博物館一個必去點。露天博物館排下午不是妥協，是因為**旅行團集中在上午**。
- **11/03 = Kaymaklı（第一站）→ 鴿子谷 → Uçhisar Castle → 路過 Göreme 拿行李 → Gamirasu**。⚠️ **退房後行李寄放 Grand Elite，全天不上車。**
- **11/04 = Avanos 河邊午餐 + Sarı Han 商隊驛站 + ASR**（原本的 Avanos 陶藝與 Paşabağ 已取消，改補塞爾柱建築）。⚠️ **三天裡唯一行李必須待在車上的一天。**

**駱駝永遠固定 11/02 16:00**（2026-08-19 由 15:00 改為 GetYourGuide 的日落場，因為 **11/02 Göreme 日落是 17:41**，騎乘 16:20～17:20 整段落在黃金時段）：它的免費取消期限是 11/01 16:00，而那時還不知道 11/02 熱氣球會不會飛，所以「等消息再決定」這條路本來就不存在。釘死之後 11/02 + 11/03 的總車程從浮動版的 145 分降到 **120 分**，而且永遠不需要取消。

### 11/03 為什麼從 85 分變成 120 分車程

|  | 舊版（行李直接上車） | 定版（行李寄放飯店） |
|---|---|---|
| 順序 | Göreme → Uçhisar → 鴿子谷 → Kaymaklı → Gamirasu | Göreme → **Kaymaklı** → 鴿子谷 → Uçhisar → **回 Göreme 拿行李** → Gamirasu |
| 車程 | 10 + 5 + 40 + 30 = **85 分** | 35 + 40 + 5 + 10 + 30 = **120 分** |
| 行李在車上 | 全天約 6 小時，含 Kaymaklı 停車場 1.5 小時 | **0**（拿回後直接開到飯店門口，不再停景點） |
| 進 Gamirasu | 16:55 | **15:45** |

**多出的 35 分就是「行李一整天不上車」的價碼**，而且順便把進飯店的時間提早了 70 分。租的 Opel Crossland 是掀背車、訂單只寫 2 Large bag，兩個 26 / 28 吋箱子放後車廂會從後窗看得到；Kaymaklı 又是全天停最久（1.5h）、離飯店最遠（32 km）的點。最後 Grand Elite → Gamirasu 那段跟 Kaymaklı → Gamirasu 一樣長（OSRM 27.1 vs 27.4 分），所以**回頭拿行李沒有讓收尾變遠**。

### 每日疲勞度總覽

疲勞度以交通時間、早起程度、換飯店 / 取還車、景點步行量與是否有深夜抵達綜合判斷。等級定義：`低` = 可慢走與休息；`中` = 正常景點日；`中高` = 需要控體力；`高` = 當天容易累積疲勞；`很高` = 需要預留刪減方案。
